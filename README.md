# TDL TypeScript Junior Course

Course material for the **TestDevLab (TDL) TypeScript Junior** course (September 2026 group).
Code from the lectures, end-of-day tasks and the Task Manager project.

## Structure

| Path | Contents |
|------|----------|
| `src/Theory/` | Lecture examples and end-of-day tasks |
| `src/task_manager/` | Task Manager CLI project (see `infoManager.md`) |
| `var_let/` | Small `var` vs `let` comparison example |
| `info.md` | Notes: TypeScript basics |
| `daytask1.md` | End-of-day task 1 description |

## Setup

Requires [Node.js](https://nodejs.org/) (LTS).

```bash
npm install     # install TypeScript and Node types
npx tsc         # compile src/ into dist/
```

## Run the Task Manager

Main entry point (runs the scripted demo):

```bash
node dist/task_manager/index.js
```

Interactive CLI version (type commands yourself):

```bash
node dist/task_manager/cli.js
```

CLI commands: `add <title>`, `list`, `complete <id>`, `delete <id>`, `summary`, `help`, `exit`.

## Notes

- `dist/` is generated by `npx tsc`; do not edit it by hand.
- Open the folder in VS Code for live type errors while you edit.
