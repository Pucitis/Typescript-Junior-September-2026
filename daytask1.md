Build a Student Registry
Part 1.
    Create a type called Student with the following properties
    id - can be either a number or a string
    name - must be a string
    age - must be a number
    grade - must be number
    email - optional string
    isEnrolled - must be a boolean and CANNOT be changed after creation



Part 2.
Create three Student Objects
    1. A student named "Anna", age 20, grade 9, id 1, enrolled, no email
    2. A student named "Tom", age 22, grade 7, id "tom-42", not enrolled, with an email
    3. A student of your own choice, fill in all fields including an email.

    EXTRA points - store all of these three Students in an array called Students. MAKE sure the array has the correct type!


Part 3.
Use typeof and Conditionals
You are given this variable
    let studentID: unknown = "stu-001";

Write an if / else statement that
    check if studentId is a string
    if it is a string, print out "Searching for student with String ID"
    if it is not a string print out "ID must be a string"
    Then reasign the studentID to a number value and run the same check again.
