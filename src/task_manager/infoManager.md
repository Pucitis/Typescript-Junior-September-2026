# Task Manager App


---


### What it does

- Tasks have a title, description, priority, status and an assigned user
- Users can create tasks, complete them, and delete them
- Tasks can be filtered by status or by priority
- a generic utility function can display any colletion of items or just tasks
- no "any" usage, everiting is types with interfaces, enumds, generics ad classes


## File structure

- enums.ts
- types.ts
- utils.ts
- taskManger.ts
- user.ts
- index.ts - you can call this whtever.
